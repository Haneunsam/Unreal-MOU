# 개발자용 마이크 게이지 상한

`WBP_VoiceStatusWidget`의 Class Defaults → MOU → Voice → Intensity → **Maximum Voice RMS**에서 설정한다. 기본값은 0.05이며 기존 고정값은 0.25였다. 값이 작을수록 작은 목소리로 100%에 도달한다.

사용자 감도는 입력을 통과시키는 하한이고 Maximum Voice RMS는 통과한 음성이 최대 강도에 도달하는 상한이다. 예를 들어 하한 0.01, 상한 0.05에서 RMS 0.03은 강도 50%, RMS 0.05는 100%다. 게이지에는 기존 시각적 보간이 적용된다.

같은 강도를 음성 패킷에 실어 보내므로 서버의 NPC 소음 반경 및 수신 측 가청 거리도 기존 반경 곡선에 따라 함께 변한다. 강도 50%가 거리 50%라는 뜻은 아니며, 기존 최소 반경과 곡선은 유지한다. 일반/무전 수신 게인도 유지한다.

블루프린트 기본값은 로컬 음성 서브시스템 초기화 때 읽고 실제 HUD 인스턴스 값은 생성/갱신 때 해당 플레이어에 반영한다. 다른 로컬 플레이어의 상한은 변경하지 않는다. 사용자 감도가 개발자 상한 이상이면 하한 위에 작은 유효 구간을 두어 0으로 나누거나 모든 발화가 즉시 100%가 되는 현상을 방지한다.
