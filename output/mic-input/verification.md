# 마이크 입력 감도 변경 검증

- 두 환경설정: 원본 RMS 입력 바 + 차단 경계 슬라이더. -80~0 dBFS 로그 눈금이며 맨 왼쪽은 임계값 0.
- 노란 구간: 차단 영역. 초록 구간: 통과 영역. 검은 바탕 위의 밝은 채움이 실제 입력량.
- HUD 마이크: 전송에 쓰는 GetCurrentIntensity/NormalizeLoudness와 동일한 강도를 표시.
- Windows 엔진 선행 SilenceDetectionThreshold/MicNoiseGateThreshold를 -1로 설정하여 게임 VAD 전에 작은 입력이 사라지는 현상 방지.
- 발화 종료 시 기존의 짧은 hangover는 말끝 잘림 방지를 위해 유지.
- 일반 음성 2.0 / 무전기 2.5 수신 게인 유지.

## 확인 결과

`MOU.Voice.InputSensitivity` 자동 테스트 통과: 실제 PCM 프레이밍으로 무음/작은 입력/임계값 전후 판정, 차단 전 RMS 조회, 말끝 유지 후 차단, 로그 변환 왕복, 음량 강도의 증가, 기존 수신 게인 검사.

`verify.py` PIE 검사 10개 통과: 엔진 선행 게이트 해제, 로비/인게임 위젯 종류, 아이콘 미리보기 제거, 임계값 0 적용, 로비에서 인게임으로 설정 공유, -60 dB 적용, PIE 재시작 후 저장 복원. 결과는 `results.json`.

무음 출력 옵션과 기본 GameMode로 UI/로컬 서브시스템 연결을 검사했다. 두 실제 플레이어 간 마이크 청취 및 다양한 하드웨어의 작은 목소리 인식률까지 검사한 결과는 아니다.
