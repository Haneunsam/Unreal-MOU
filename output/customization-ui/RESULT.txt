WBP_LobbyCustomizeWidget: 팀원 CharacterCustomization Blueprint를 복제하고 LobbyCustomizeWidgetBase로 재부모화.

원본 NPC 위젯과 C++ 파일은 변경하지 않음.

검증: Blueprint 4개 컴파일, 원본 그래프 목록 보존, 두 PIE 클라이언트 + 별도 서버 14개 런타임 검사 통과.
RoomCustomizationTest, RoomSlotsTest 통과.
취소/확인/재진입, 확인 전 서버 상태 불변, 확인 후 양쪽 참여자 슬롯 1 갱신과 방장 외형 유지 확인.

데칼 4, 데칼 색상 (0.8,0.2,0.1,1), 반복 X 2.5/Y 3.5가 저장됨.
사전 백업이 없어 이전 User_2 외형을 확실하게 복원하지 못함. 추측으로 복원하지 않았음.
