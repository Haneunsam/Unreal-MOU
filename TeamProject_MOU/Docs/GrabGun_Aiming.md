# 그랩건 조준 방향 보정

- 발사 순간 서버가 사용자 카메라에서 `GrabRange`까지 Visibility 트레이스를 수행한다. 충돌 위치 또는 최대 거리 지점을 조준 목표로 저장한다.
- 총몸의 장착 위치·회전은 유지하고 `LinkageRoot`의 로컬 +X 축을 목표 쪽으로 회전시킨다. 따라서 집게 연결부가 회전하는 방식이며 팔 애니메이션을 바꾸지는 않는다.
- 목표와 조준 활성 상태를 복제하여 서버와 클라이언트가 같은 목표를 사용한다. 접히는 동안 방향을 유지하고 완전히 접히면 기존 링크 회전으로 돌아간다.
- 기존 집게 접촉 판정과 실제 펼침 길이는 유지한다. `GrabRange`는 조준 목표 탐색 거리이며 링크 자체를 그 길이로 늘리지 않는다.
- BP의 `HandLocationOffset`과 `HandRotationOffset`은 손잡이 자세 조정에 사용한다. 기존 `MeshOrientationFix`가 0이 아니면 총몸 회전을 매 프레임 덮어쓰므로 공통 장착 회전을 사용하려면 0으로 설정한다.

## PIE 확인

에디터 재시작 후 정면·위·아래의 가까운 대상을 조준해 발사한다. 집게 방향, 접촉 시 잡기, 헛발사 후 복귀, 수납·재장착을 확인한다. 2인 PIE에서 호스트·클라이언트 각각 발사해 다른 화면에서도 방향이 일치하는지 확인한다. 시각·멀티플레이 검증은 아직 수행하지 않았다.
